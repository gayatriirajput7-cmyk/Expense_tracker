## 🚀 Overview

The **Personal Expense Tracker** is a dynamic web application designed to help users track their daily *kharcha* (expenses) cleanly and professionally. Built entirely in Python using the Streamlit framework, this application transitions traditional terminal-based logic into a modern, interactive, and user-friendly web interface.

---

## ✨ Features

- **➕ Add Expenses Seamlessly:** Log your transactions with specific dates, categorizations (Food, Travel, Education, etc.), detailed descriptions, and exact amounts using clean UI form elements.
- **📋 Interactive Ledger:** View all logged expenses in a beautifully formatted, responsive Pandas DataFrame table.
- **📊 Real-Time Calculations:** The app dynamically calculates and displays your total spending on the fly using highly efficient native Python functions.
- **🔄 Session State Management:** Utilizes Streamlit's `session_state` to retain data securely across interactions without refreshing or losing your ongoing entries.

---

## 🛠️ Tech Stack

- **Frontend & Backend Framework:** [Streamlit](https://streamlit.io/)
- **Programming Language:** Python 3.x
- **Data Manipulation:** Pandas
